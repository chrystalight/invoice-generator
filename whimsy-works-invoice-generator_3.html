One-Time Setup: Auto-Save Location
By default your browser puts every downloaded file in your Downloads folder. To have PDFs and archive files land directly in Whimsy Works Admin instead:

Chrome/Edge: Settings → Downloads → turn on "Ask where to save each file" (then just confirm the folder each time), or click "Change" and set the default location to your Whimsy Works Admin folder.

Inside that folder, it's worth making two subfolders: Invoices (for PDFs) and Archive (for the .json data files) — then choose that subfolder in the save dialog each time.
